Thread Glyph Lab

Every icon, glyph and movement here is made from one material: the thread that runs through 6,028 matches from 1886 to today. Each mark is built from the same small grammar of strand, tick, bead, loop and knot, so the whole set looks drawn by one hand. Hover any glyph to see it sewn in, and star the ones you'd keep.

The ten navigation icons, current set on the left, thread set on the right. The current icons are borrowed from generic UI (a compass, a database, a line chart); each thread version draws the destination from what the section holds.

03

Match events

Small marks for timelines, lineups and match rows. The house rule applies here too: position carries the side. United events sit above the thread and opponent events hang below it.

04

Result, form and coverage

W-D-L as tension, not only colour: a win lifts the thread, a draw keeps it level, a loss pulls it down, so the shape survives greyscale. Coverage is drawn as weave density, using the record's real completeness figures.

Coverage as weave · real figures, all 6,028 matches

05

Where thread meets football

The nostalgic bridge: football already has thread in it. Laced leather balls, laced collars, knitted bar scarves, goal nets, perforated ticket stubs and stitched programmes. These are the places the brand can draw on memory without reaching for club marks.

Motion bench

Twenty-one working prototypes. Each one starts in its finished state so nothing is hidden at rest. Press its button to run it again. Where a piece breaks the current motion rules in DESIGN.md, it says so.
