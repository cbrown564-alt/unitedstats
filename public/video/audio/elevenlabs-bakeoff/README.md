# ElevenLabs soundtrack bake-off

Four 30-second instrumental auditions for the most demanding window of the European master, `00:38–01:08` (Treble build through Fergie-time pressure).

Listen against the same picture and score each candidate from 1–5 on:

1. **Fact legibility** — on-screen claims remain easy to absorb.
2. **Thread fit** — the moving red filament feels like the protagonist.
3. **Arc control** — three landings build, then the clock section creates real negative space.
4. **Distinctiveness** — sounds authored for UnitedStats, not stock sports media.
5. **Restraint** — avoids triumphal, sentimental, trailer and EDM clichés.
6. **Extension potential** — could sustain the full 90 seconds without fatigue.

Recommended decision rule: double-weight fact legibility and thread fit. Reject any candidate scoring below 3 on restraint, regardless of total.

Regenerate deliberately with `node scripts/generate-elevenlabs-bakeoff.mjs --force`. Existing files are cached by default.
